T3 Code D3SOX

A fork of T3 Code with queued follow-up messages, clearer image previews, remote-terminal fixes, and privacy-minded defaults. Signed nightly builds are available for Android and Arch Linux.

Source and feature list Latest builds

Android

Download the latest T3-Code-D3SOX-Android APK from GitHub Releases, or use the Obtainium link in the README for updates. It installs alongside upstream T3 Code.

Arch Linux

Add the signed repository following the key and pacman setup instructions, then install: 

sudo pacman -Syu t3code-d3sox-git

The package replaces t3code-bin. The repository URL is https://d3sox.me/t3code/arch/$arch.
