T3 Code D3SOX

A fork of T3 Code with changes to agent workflows, remote use, and privacy. Signed nightly builds are available for Android and Arch Linux.

Source Latest builds

What this fork changes

  • Follow-up messages wait until the agent finishes its current turn. In Settings, you can instead steer at the next tool call or immediately; the oldest queued message has buttons for both actions.
  • Images an agent opens appear in their own timeline rows, even when the rest of the turn is collapsed. The preview starts collapsed; open the row to show it, then click the preview to see the full image.
  • Pinned and Active sidebar labels stay visible without dragging a thread.
  • Pull request links open in your system browser by default. On desktop, right-click one to open it in T3 Code instead. When a repository has both origin and upstream, T3 Code uses origin for the fork's pull requests.
  • The new-thread button remembers the last project you started a thread in, even while viewing another project's thread. Shift-click it to choose a different project.
  • Automatic thread titles and worktree branch names can be turned off for an environment or project in Settings → Source Control.
  • Opening a path from a remote terminal shows the file in T3 Code, not on the remote machine.
  • Closing a terminal does not ask for confirmation. Ctrl+D still goes to the terminal.
  • Product usage collection is off unless you set T3CODE_TELEMETRY_ENABLED=true on the server.

Android nightly

Download the latest T3-Code-D3SOX-Android APK from GitHub Releases, or use the Obtainium link in the README for updates. It installs alongside upstream T3 Code as a separate preview app. This build does not use upstream Expo over-the-air updates or export app telemetry.

Arch Linux nightly

The signed t3code-d3sox-git package updates through pacman. First, download the repository signing key and check that its fingerprint is 5A4D 66D6 9437 77AD 48A5 F169 9728 12D8 A4CF BA4D: 

wget -O t3code-d3sox.asc https://raw.githubusercontent.com/D3SOX/t3code/main/packaging/aur/t3code-d3sox-git/signing-key.asc
gpg --show-keys --fingerprint t3code-d3sox.asc

Only after the fingerprint matches, trust the key for packages from this repository:

sudo pacman-key --add t3code-d3sox.asc
sudo pacman-key --lsign-key 5A4D66D6943777AD48A5F169972812D8A4CFBA4D

Add this section to /etc/pacman.conf:

[t3code-d3sox]
SigLevel = Required
Server = https://d3sox.github.io/t3code/arch/$arch

Install the package and get future nightly updates with your normal pacman updates:

sudo pacman -Syu t3code-d3sox-git

The repository keeps the newest x86_64 package; older builds remain in GitHub Releases. The package conflicts with t3code-bin, so pacman will ask to replace it. To build from source instead, see the README.
